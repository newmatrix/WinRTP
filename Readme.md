# 🛠️ Windows Repair Tool Pro
**الإصدار:** v1.4 | **المنصة:** أنظمة تشغيل Windows

أداة شاملة ومتقدمة لصيانة، إصلاح، وتحسين أداء نظام الويندوز بضغطة زر واحدة. تم تصميم هذه الأداة لتوفير الوقت والجهد على الفنيين والمستخدمين من خلال تجميع أقوى أوامر الصيانة في واجهة تفاعلية بسيطة وآمنة. تتمتع الأداة بخاصية طلب صلاحيات المسؤول تلقائياً لضمان تنفيذ المهام بصلاحيات كاملة[cite: 3].

---

## ⚠️ ملاحظة هامة بشأن برامج الحماية (Antivirus)
قد تقوم بعض برامج مكافحة الفيروسات (مثل Windows Defender) بالتعرف على هذه الأداة كملف ضار أو إيقاف تشغيلها. هذا أمر طبيعي جداً ويُعرف برمجياً بـ **"الإيجابية الخاطئة" (False Positive)**.

**السبب التقني:**
الأداة مصممة للقيام بصيانة عميقة للنظام، مما يتطلب تنفيذ أوامر برمجية قوية مثل:
* إيقاف وتعديل خدمات الويندوز الأساسية (مثل التحديثات وخدمات الحماية)[cite: 3].
* التعديل المباشر على مفاتيح الريجستري (Registry) لتحسين الأداء[cite: 3].
* التعامل المباشر مع مكونات النظام باستخدام أوامر الدوس (CMD) والـ (PowerShell)[cite: 3].

بما أن البرمجيات الخبيثة تستخدم أحياناً أوامر مشابهة للوصول إلى النظام، تقوم برامج الحماية بحظر أداتنا كإجراء احترازي أوتوماتيكي. **الأداة آمنة تماماً ومبرمجة بأكواد نظام Windows القياسية.** يُنصح بإيقاف برنامج الحماية مؤقتاً أثناء الاستخدام، أو إضافة الأداة إلى قائمة الاستثناءات (Exclusions).

## 🌟 الميزات الرئيسية والأقسام

### 🛡️ 0. إنشاء نقطة استعادة (Create Restore Point)
* إنشاء نقطة استعادة للنظام بنقرة واحدة لضمان أمان ملفاتك وإعداداتك قبل إجراء أي تغييرات[cite: 3].

### 🚀 1. تحسين النظام (Optimize OS)
قسم مخصص لتسريع الويندوز وتوفير مساحة التخزين:
* إصلاح ملفات النظام العميقة باستخدام تقنية (DISM RestoreHealth)[cite: 3].
* تنظيف مخزن المكونات (Component Store) لإصلاح التحديثات المعلقة[cite: 3].
* حذف ملفات التحديثات القديمة ومجلد (Windows.old) لتحرير مساحة التخزين[cite: 3].
* فحص وإصلاح ملفات الويندوز التالفة (SFC Scan)[cite: 3].
* مسح الملفات المؤقتة لتسريع التصفح والأداء[cite: 3].
* تحسين إعدادات الإنترنت ومسح ذاكرة التخزين المؤقت للـ DNS[cite: 3].
* تعطيل تطبيقات الخلفية لتوفير استهلاك الذاكرة العشوائية (RAM)[cite: 3].

### 💾 2. أدوات الأقراص (Disk Tools)
تحكم كامل في الأقراص الصلبة ووحدات التخزين:
* جدولة فحص وإصلاح أخطاء القرص (CHKDSK)[cite: 3].
* التحسين الذكي للأقراص (Defrag لـ HDD و TRIM لـ SSD)[cite: 3].
* فحص الحالة الصحية الفيزيائية للأقراص (S.M.A.R.T Status)[cite: 3].
* الحذف الآمن (Secure Wipe) للمساحة الفارغة لمنع استرجاع الملفات المحذوفة[cite: 3].
* اختبار سرعة القراءة والكتابة للقرص (Benchmark)[cite: 3].
* أداة إنقاذ الفلاشات وإظهار الملفات المخفية بفعل الفيروسات[cite: 3].
* أداة الإصلاح العميق لمشكلة "القرص محمي ضد الكتابة" (Write Protection Fixer)[cite: 3].

### ⚙️ 3. أدوات متقدمة (Advanced Tools)
خيارات مخصصة للمحترفين:
* تفعيل وضع "الأداء الفائق" (Ultimate Performance Mode) للطاقة[cite: 3].
* جدولة الإغلاق التلقائي للكمبيوتر أو إلغاء جدولته[cite: 3].
* إعادة التشغيل مباشرة إلى إعدادات اللوحة الأم (BIOS/UEFI) أو الوضع الآمن[cite: 3].
* إزالة تطبيقات الويندوز الافتراضية غير الضرورية (Debloat Windows)[cite: 3].
* كشف وعرض كلمات مرور شبكات الـ Wi-Fi المحفوظة[cite: 3].
* إيقاف أو تشغيل تحديثات الويندوز بشكل جذري[cite: 3].
* مغير الـ DNS الذكي لتحسين الاتصال للألعاب والتصفح (Cloudflare, Google, وغيرها)[cite: 3].
* تنظيف الذاكرة المؤقتة لمنصات الألعاب (Steam, Epic, EA, Discord)[cite: 3].
* استخراج مفتاح الويندوز الأصلي (OEM Key) المدمج في اللوحة الأم[cite: 3].

### 🔧 4. إصلاح الويندوز (Repair OS)
حلول سريعة لأكثر مشاكل الويندوز شيوعاً:
* الإصلاح العميق لخدمة تحديثات الويندوز[cite: 3].
* إصلاح وإعادة ضبط متجر مايكروسوفت والتطبيقات الافتراضية[cite: 3].
* إعادة بناء ذاكرة التخزين المؤقت للأيقونات والصور المصغرة[cite: 3].
* إصلاح شريط المهام، قائمة ابدأ، ومدير الملفات (Explorer)[cite: 3].
* إصلاح خدمات الصوت والبلوتوث والطابعات (Print Spooler)[cite: 3].

### 🛡️ 5. الأمان والخصوصية (Security & Privacy)
* مسح سجل الحماية الخاص بـ Defender لحل مشكلة الإشعارات الوهمية[cite: 3].
* الإصلاح العميق لبرنامج Windows Defender وإعادة تشغيل خدماته[cite: 3].
* إعادة ضبط جدار الحماية وملف الـ Hosts للوضع الافتراضي[cite: 3].
* تعطيل خدمات تتبع البيانات (Windows Telemetry) لحماية الخصوصية[cite: 3].

### 💽 6. إدارة التعريفات (Drivers Manager)
* البحث عن تحديثات للتعريفات وتثبيتها[cite: 3].
* أخذ نسخة احتياطية (Backup) شاملة لجميع التعريفات المثبتة واستعادتها (Restore) بنقرة واحدة[cite: 3].
* إزالة التثبيت الصامت لتعريفات محددة من الجذور[cite: 3].

### 📦 7. التثبيت الصامت للبرامج (Winget)
مركز متكامل لإدارة البرامج:
* تحديث جميع البرامج المثبتة تلقائياً[cite: 3].
* تثبيت جميع الحزم الأساسية (C++, DirectX, .NET, Java) بضغطة واحدة[cite: 3].
* قائمة لتثبيت أشهر البرامج بصمت، مع محرك بحث مدمج للبحث عن أي تطبيق عبر الإنترنت[cite: 3].
* أداة الغاء التثبيت الصامت للبرامج من جذورها[cite: 3].

### 👤 8. إدارة حسابات المستخدمين (User Accounts Manager)
تحكم استثنائي في حسابات الويندوز:
* إضافة، حذف، أو إعادة تسمية حسابات المستخدمين وتغيير كلمات المرور[cite: 3].
* منح أو سحب صلاحيات المسؤول (Administrator)[cite: 3].
* إخفاء الحسابات من شاشة تسجيل الدخول أو إظهارها[cite: 3].
* تجميد الحسابات مؤقتاً أو تفعيل حساب المسؤول المدمج مع النظام[cite: 3].
