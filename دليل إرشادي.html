دليل أداة Windows Repair Tool Pro

تم تطوير هذه الأداة بواسطة Hesham Taha لتقديم صيانة شاملة وإصلاح وتحسين لنظام التشغيل Windows[cite: 1, 232].

تحسين النظام وتحديثه

  • Run DISM RestoreHealth: تقوم بفحص صحة صورة النظام وإصلاح الملفات التالفة باستخدام أداة DISM[cite: 4, 25].
  • Component Store Cleanup: تنظيف عميق لمخزن مكونات ويندوز لتوفير مساحة في القرص[cite: 4, 26].
  • Clean Old Windows Updates: حذف ملفات التحديثات القديمة ومجلد Windows.old لتوفير مساحات كبيرة[cite: 4, 27].
  • Clean Crash Dumps Files: مسح ملفات تقارير الأخطاء والانهيارات (Minidump)[cite: 4, 29].
  • Run SFC Scan: فحص وإصلاح ملفات النظام الأساسية التالفة باستخدام أمر sfc /scannow[cite: 4, 30].
  • Clean Temporary Files: إفراغ مجلدات Temp و Prefetch من الملفات المؤقتة لتسريع الجهاز[cite: 4, 31].
  • Optimize Internet & DNS: تفريغ الـ DNS وإعادة تعيين محولات الشبكة لتسريع وحل مشاكل الإنترنت[cite: 4, 32].
  • Clear Event Viewer Logs: مسح سجلات أحداث نظام ويندوز لتوفير المساحة[cite: 4, 33].
  • Disable Background Apps: إيقاف تشغيل التطبيقات في الخلفية لتوفير استهلاك الذاكرة العشوائية (RAM)[cite: 4, 34, 35].
  • Clear Delivery Optimization Cache: مسح ذاكرة التخزين المؤقت لملفات التحديثات المشتركة[cite: 4, 36].
  • Safe and quick cleaning: خيار يقوم بتنظيف وإصلاح سريع يشمل أهم الخيارات (SFC, Temp, DNS) بضغطة واحدة[cite: 5, 37].

إدارة وأدوات الأقراص الصلبة

  • Schedule CHKDSK Scan: جدولة فحص القرص الصلب لإصلاح الأخطاء (يعمل فورا للأقراص الفرعية أو عند إعادة التشغيل لقرص النظام C)[cite: 7, 38, 41].
  • Stop Scheduled CHKDSK Scan: إلغاء الفحص المجدول للقرص قبل إعادة التشغيل[cite: 7, 43, 46].
  • Smart Disk Optimization: تحسين ذكي للأقراص، يقوم بعمل (Defrag) لأقراص HDD و (TRIM) لأقراص SSD[cite: 7, 48].
  • Check Disk Health: فحص الحالة الفيزيائية للقرص (S.M.A.R.T) لمعرفة ما إذا كان سليماً أم معرضاً للتلف[cite: 7, 52, 53].
  • View Disk Storage Information: عرض تفاصيل السعة والمساحة الحرة لجميع الأقراص[cite: 7, 55].
  • Secure Wipe Free Space: كتابة بيانات عشوائية فوق المساحة الفارغة لمنع استعادة الملفات المحذوفة نهائياً (لا يمسح ملفاتك الحالية)[cite: 7, 56, 60].
  • Disk Speed Test: اختبار أداء وسرعة القراءة والكتابة للقرص[cite: 7, 61, 63].
  • USB/Drive Virus Rescue: إظهار الملفات المخفية بسبب الفيروسات وإزالة خصائص النظام عنها لاستعادتها[cite: 7, 64, 66].
  • USB Write Protection Fixer: إصلاح مشكلة "القرص محمي ضد الكتابة" للفلاشات وكروت الميموري[cite: 7, 68, 70].

الأدوات المتقدمة وإعدادات النظام

  • Enable Ultimate Performance: تفعيل خيار الأداء الأقصى المخفي في ويندوز للحصول على أعلى كفاءة[cite: 9, 75].
  • Restore Balanced Mode: العودة لوضع الطاقة المتوازن وحذف ملفات الأداء الأقصى[cite: 9, 77].
  • Schedule / Cancel Auto Shutdown: جدولة إيقاف تشغيل الكمبيوتر بعد عدد معين من الدقائق، أو إلغائها[cite: 9, 79, 80].
  • Restart to BIOS/UEFI / Safe Mode: إعادة التشغيل مباشرة للدخول إلى شاشة البيوس أو الوضع الآمن[cite: 9, 81, 83].
  • Debloat Windows: إزالة تطبيقات ويندوز الافتراضية غير الضرورية (مثل Bing, Zune, Skype)[cite: 9, 85].
  • Show WI-FI Passwords: استخراج وعرض كلمات مرور شبكات الواي فاي المحفوظة مسبقاً على الجهاز[cite: 9, 87].
  • Disable / Enable Windows Update: إيقاف خدمات تحديث ويندوز بشكل جذري لمنع التحديثات التلقائية، أو إعادة تفعيلها[cite: 10, 89, 91].
  • Change Internet DNS (Gaming): تغيير خوادم DNS (مثل Cloudflare, Google, AdGuard) لتحسين السرعة أو حجب الإعلانات[cite: 10, 167, 169, 173].
  • Clean Gamers Cache: مسح ملفات التخزين المؤقت لمنصات الألعاب (Steam, EA, Epic Games, Discord)[cite: 10, 93].
  • Extract Original Windows Key: استخراج مفتاح الويندوز الأصلي (OEM) المدمج باللوحة الأم وحفظه في ملف[cite: 10, 95].
  • Context Menu Manager: إضافة أداة "Take Ownership" لقائمة الزر الأيمن للماوس للحصول على صلاحيات التعديل على ملفات النظام المحمية[cite: 10, 97, 98].
  • BSOD Log Analyzer: فحص وتحليل سجلات النظام لمعرفة أسباب ظهور الشاشة الزرقاء (Blue Screen)[cite: 10, 101].
  • Full System Backup: أخذ نسخة احتياطية كاملة (Image) للنظام والتطبيقات والتعريفات لحفظها على قرص آخر[cite: 10, 103, 105].

إصلاح أخطاء نظام التشغيل

  • Deep Repair Windows Update: إيقاف وتنظيف عميق لمجلدات التحديثات التالفة لإصلاح مشاكل تعليق التحديث[cite: 12, 110].
  • Repair Store & Default Apps: إعادة تعيين متجر مايكروسوفت وإعادة تسجيل تطبيقات ويندوز الافتراضية[cite: 12, 112].
  • Rebuild Icons & Thumbnails: مسح وإعادة بناء ذاكرة التخزين المؤقت للأيقونات المصغرة لإصلاح الأشكال التالفة[cite: 12, 114].
  • Fix Taskbar, Search & Explorer: إعادة تشغيل متصفح الملفات وإصلاح مشاكل توقف شريط المهام والبحث السريع[cite: 12, 116].
  • Fix Audio Services: إعادة تشغيل خدمات الصوت الخاصة بويندوز لحل مشاكل انقطاع الصوت[cite: 12, 118].
  • Fix Bluetooth Services: إعادة تشغيل الخدمات الداعمة للبلوتوث لإصلاح مشاكل الاقتران[cite: 12, 120].
  • Fix Printer & Spooler: مسح مهام الطباعة العالقة وإعادة تشغيل خدمة الطباعة (Spooler)[cite: 12, 122].
  • Restart Core Services: إعادة تشغيل الخدمات الأساسية الهامة لويندوز بنقرة واحدة[cite: 12, 124].

الأمان والخصوصية (Windows Defender)

  • Quick / Full Virus Scan: إجراء فحص سريع أو عميق للبحث عن الفيروسات والملفات الضارة باستخدام Windows Defender[cite: 14, 126, 127].
  • Offline Virus Scan: إعادة تشغيل الجهاز وعمل فحص قبل إقلاع النظام، وهو مفيد لحذف الفيروسات العنيدة (Rootkits/Trojans)[cite: 14, 129].
  • Clear Defender History: مسح سجل الحماية وإشعارات التهديدات القديمة التي تستمر بالظهور كخلل[cite: 14, 131].
  • Deep Repair Windows Defender: إزالة القيود المفروضة من الفيروسات على Defender، وإعادة تسجيل خدماته وتحديثه[cite: 14, 132, 133].
  • Reset Windows Firewall: إعادة تعيين جدار الحماية (Firewall) إلى الإعدادات الافتراضية[cite: 14, 137].
  • Reset Hosts File: استعادة ملف Hosts الأصلي لحل مشاكل تحويل الروابط المزعجة الناتجة عن البرمجيات الخبيثة[cite: 14, 138].
  • Disable / Enable Windows Telemetry: إيقاف (أو تفعيل) خدمات تتبع البيانات وإرسالها لمايكروسوفت (لتعزيز الخصوصية)[cite: 14, 140, 141].

إدارة تعريفات الأجهزة

  • Check & Install Driver Updates: فحص سيرفرات مايكروسوفت لتحديث تعريفات النظام الأساسية وتثبيتها[cite: 16, 142, 147].
  • Backup All Installed Drivers: إنشاء مجلد احتياطي يحتوي على جميع التعريفات المثبتة حالياً على الجهاز لاستخدامها لاحقاً (مثلاً بعد الفورمات)[cite: 16, 150, 153].
  • Restore Drivers From Backup: استعادة وتثبيت التعريفات من النسخة الاحتياطية المحفوظة مسبقاً بصمت[cite: 16, 155, 157].
  • Uninstall Specific Driver: إزالة تعريف معين نهائياً من جذور النظام بواسطة اسم الملف (oem.inf)[cite: 16, 160, 163].

تثبيت التطبيقات وإدارتها (Winget)

  • Update / Uninstall Installed Programs: معالجات تفاعلية لتحديث كافة التطبيقات أو حذف تطبيق محدد بصمت من الجذور[cite: 176, 187, 190].
  • Install ALL Core Runtimes: تثبيت صامت لكافة الحزم والبرامج المساعدة التي تحتاجها الألعاب والبرامج الثقيلة (Visual C++, DirectX, .NET, Java الخ)[cite: 176, 181, 182].
  • Silent Apps Installer: قائمة جاهزة لتثبيت أشهر البرامج بصمت وبدون تدخل (Chrome, Discord, IDM, WinRAR, Steam وغيرها)[cite: 176, 179].
  • Search & Install Custom App: البحث في قاعدة بيانات مايكروسوفت لتثبيت أي تطبيق آخر برقم الـ ID الخاص به[cite: 178, 195, 198].

إدارة حسابات المستخدمين

  • Add / Delete / Rename User: إضافة حساب محلي جديد، حذف حساب بالكامل، أو تغيير اسم مستخدم موجود[cite: 23, 200, 203, 206].
  • Change Existing User Password: تعيين كلمة مرور جديدة لأي حساب محلي أو إزالتها كلياً[cite: 23, 209].
  • Grant / Revoke Administrator Privileges: ترقية حساب عادي ليصبح مدير (Admin)، أو سحب الصلاحيات منه[cite: 23, 212, 215].
  • Hide / Show Account: إخفاء حساب معين بحيث لا يظهر في شاشة تسجيل الدخول العادية، أو إظهاره مجدداً[cite: 23, 218, 221].
  • Freeze / Unfreeze Account: تعطيل الدخول إلى الحساب مؤقتاً (تجميد)، أو إعادة تفعيله[cite: 23, 224, 225].
  • Toggle Built-in Administrator: تفعيل أو تعطيل حساب المدير المخفي (الأساسي) المدمج في ويندوز[cite: 23, 227, 228].
  • View Detailed User Info: عرض تقرير شامل وصلاحيات حساب مستخدم معين[cite: 23, 230, 231].
